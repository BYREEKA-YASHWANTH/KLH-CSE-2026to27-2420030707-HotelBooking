## Abstract

Hotel booking cancellations can affect occupancy planning, revenue management, and the efficient allocation of hotel resources. This project analyzes historical hotel booking data to examine cancellation patterns and customer booking behavior. It uses data cleaning, exploratory data analysis, statistical comparisons, and visualization to investigate patterns associated with variables such as lead time, hotel type, deposit type, market segment, and customer type. The findings will be presented through meaningful visualizations and, if feasible, an interactive dashboard.

## Dataset

**Dataset:** Hotel Booking Demand Dataset

**Source:** https://www.kaggle.com/datasets/jessemostipak/hotel-booking-demand

The project uses historical booking records from city and resort hotels. Dataset acquisition, preprocessing, and analysis will be documented in the project repository.
